# 5. 最終特徴量テーブル作成計画

## 目的
時間領域と周波数領域で生成したすべての特徴量を統合し、モデル学習に使用する単一のテーブルを作成する。

## 手法
- Python (Notebook): Pandas DataFrameをマージする。
- dbt: （オプション）Pythonで作成した特徴量テーブルを再度データベースにロードし、dbtモデルとして管理する。

## タスク
1.  **特徴量の結合**:
    - 時間領域特徴量と周波数領域特徴量を、ウィンドウIDやタイムスタンプをキーとして結合する。
2.  **ラベル付け**:
    - 各ウィンドウに対応する活動ラベル（`activity`）を付与する。
3.  **不要な列の削除**:
    - 元データや中間生成物など、モデル学習に不要な列を削除する。
4.  **最終確認**:
    - テーブルに欠損値がないか、データ型が適切か最終確認を行う。
5.  **保存**:
    - 作成したテーブルをParquetやCSV形式で保存する。
