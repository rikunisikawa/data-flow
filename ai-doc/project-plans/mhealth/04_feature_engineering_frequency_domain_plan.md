# 4. 特徴量エンジニアリング計画（周波数領域）

## 目的
時系列センサーデータを周波数領域に変換し、活動の周期的なパターンを捉える特徴量を生成する。

## 手法
- Python (Notebook): NumPyやSciPyのFFT（高速フーリエ変換）ライブラリを使用する。

## 生成する特徴量
時間領域と同様のスライディングウィンドウに対し、FFTを適用して以下の特徴量を計算する。

1.  **スペクトルエネルギー**:
    - `spectral_energy`: 周波数スペクトルのエネルギー
2.  **主要周波数成分**:
    - `dominant_frequency`: 最もパワースペクトルが大きい周波数
    - `spectral_centroid`: スペクトルの重心
3.  **スペクトルの統計量**:
    - `spectral_entropy`: スペクトルのエントロピー
    - `spectral_skewness`: スペクトルの歪度
    - `spectral_kurtosis`: スペクトルの尖度
4.  **周波数帯域パワー**:
    - 特定の周波数帯域（例: 0-5Hz, 5-10Hz）ごとのパワー
