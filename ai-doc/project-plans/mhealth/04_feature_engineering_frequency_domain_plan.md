# MHEALTH Feature Engineering Plan: 周波数領域特徴量の作成

## 1. 目的

Python を使用して、dbt (SQL) では実装が困難な周波数領域の特徴量を計算する。FFT (高速フーリエ変換) を利用して、時系列信号を周波数成分に分解し、その特性を捉える特徴量を抽出する。

## 2. 背景

時間領域の特徴量だけでは捉えきれない、信号の周期的なパターンを分析するために周波数領域の特徴量が用いられる。例えば、歩行や走行といった活動は、それぞれ特有の周波数パターンを持つため、これらを特徴量として加えることでモデルの分類精度が向上することが期待される。

## 3. タスク詳細

### 3.1. 開発環境のセットアップ

- **作業内容**:
    1.  特徴量計算スクリプト用のディレクトリ `scripts/mhealth/` を作成する。
    2.  `numpy` や `pandas`, `scipy`, `pyarrow` (S3からParquetを読み書きするため) などのライブラリを `scripts/requirements.txt` に定義し、仮想環境にインストールする。
    3.  AWSの認証情報を設定し、スクリプトからS3バケットにアクセスできるようにする。

### 3.2. データ読み込み処理の実装

- **作業内容**:
    1.  dbtで作成した `int_mhealth_cleaned` テーブル（または `int_mhealth_windowed`）をS3経由で読み込むPython関数を作成する。
    2.  データをPandas DataFrameとして扱い、被験者IDやウィンドウIDでグループ化できるように準備する。

### 3.3. 周波数領域特徴量の計算

- **作業内容**:
    1.  各ウィンドウの各センサー信号に対して、FFTを適用する関数を実装する (`scipy.fft.fft`)。
    2.  FFTの結果から、以下の特徴量を計算するロジックを実装する。
        - **DC成分**: 直流成分（周波数が0の成分）。
        - **Spectral Energy**: スペクトルエネルギー（パワースペクトル密度の総和）。
        - **Spectral Entropy**: スペクトルエントロピー（周波数成分の分布の乱雑さを示す指標）。
        - **主要な周波数成分**: パワースペクトルが最大となる周波数とその値。
    3.  これらの計算をすべてのセンサー軸に対して行い、結果を新しいDataFrameにまとめる。

### 3.4. 結果の出力

- **作業内容**:
    1.  計算した周波数領域特徴量を、ウィンドウIDや被験者IDをキーとして、Parquet形式でS3の指定されたパス (`s3://<bucket>/mhealth/features/frequency_domain_features/`) にアップロードする関数を実装する。
    2.  このParquetファイルは、後続のdbtモデルで `source` として読み込めるようにスキーマを整える。

- **成果物**:
    - Pythonスクリプト: `scripts/mhealth/build_frequency_features.py`
    - 要件定義ファイル: `scripts/requirements.txt`
    - S3上のParquetファイル群

## 4. 完了条件

- `python scripts/mhealth/build_frequency_features.py` を実行すると、エラーなく処理が完了する。
- S3の指定パスに、スキーマが定義されたParquetファイルが正しく出力されている。
- 計算された特徴量の値が、小規模なサンプルデータに対する手計算や既知の結果と一致し、妥当であることが確認できる。
- スクリプトには、処理内容や関数の役割を説明するコメントやdocstringが適切に記述されている。
