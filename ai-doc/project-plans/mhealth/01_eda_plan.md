# 1. 探索的データ分析（EDA）計画

## 目的
MHEALTHデータセットの基本的な特性を理解し、データ品質の問題点を特定する。後の特徴量エンジニアリングやモデリングの指針を得る。

## 手法
- dbt: `cleaned_activities` モデルからデータをロードする。
- Python (Notebook): Pandas, Matplotlib, Seabornライブラリを使用する。

## 分析項目
1.  **基本統計量の算出**:
    - 各センサー（加速度、ジャイロ、etc.）の各軸（x, y, z）における平均、中央値、標準偏差、最小値、最大値を算出する。
2.  **データ分布の可視化**:
    - 各センサーデータのヒストグラムを作成し、分布の形状（正規分布、歪度など）を確認する。
    - 活動ラベル（`activity`）ごとのデータ分布を箱ひげ図で比較する。
3.  **時系列データのプロット**:
    - 特定の被験者・活動におけるセンサーデータの時系列プロットを作成し、パターンを視覚的に確認する。
4.  **センサー間の相関分析**:
    - センサーデータ間の相関係数を算出し、ヒートマップで可視化する。多重共線性の可能性を評価する。
5.  **活動ラベルの分布**:
    - 各活動ラベルのサンプル数を集計し、データセットのクラスバランスを確認する。
