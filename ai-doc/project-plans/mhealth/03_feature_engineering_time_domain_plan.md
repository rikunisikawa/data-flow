# 3. 特徴量エンジニアリング計画（時間領域）

## 目的
時系列センサーデータから、活動認識モデルの予測に有効な時間領域の特徴量を生成する。

## 手法
- Python (Notebook): Pandasの`rolling`や`groupby`機能を活用し、スライディングウィンドウ法で特徴量を抽出する。

## 生成する特徴量
固定長のウィンドウ（例: 2.56秒、50%オーバーラップ）を適用し、各ウィンドウ内で以下の統計量を計算する。

1.  **基本的な統計量**:
    - `mean`: 平均値
    - `std`: 標準偏差
    - `median`: 中央値
    - `max`: 最大値
    - `min`: 最小値
    - `range`: 最大値と最小値の差
    - `iqr`: 四分位範囲
2.  **エネルギーとパワー**:
    - `energy`: エネルギー（二乗和）
    - `rms`: 二乗平均平方根
3.  **形状に関する特徴量**:
    - `skewness`: 歪度
    - `kurtosis`: 尖度
4.  **相関**:
    - 異なる軸間の相関係数（例: `acc_x`と`acc_y`）
