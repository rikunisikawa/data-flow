# タスク4.1: モデルの評価と結果のレポーティング

## 目的

学習済みモデルの性能を、未知のデータであるテストデータセットを用いて定量的に評価する。
論文の結果と比較可能な評価指標（Accuracy, F1スコアなど）を算出し、モデルの汎化性能を明らかにする。

## 背景

モデルの学習が完了したが、そのモデルが実際にどれほどの精度で人間活動を認識できるのかは未知数である。
学習プロセスから完全に隔離されていたテストデータセットを用いることで、モデルの真の性能を評価する。
この評価結果が、論文の再現が成功したかどうかの最終的な判断基準となる。

## 作業内容

1.  **評価環境のセットアップ**
    -   学習時と同様に、評価に必要なライブラリ（`scikit-learn`, `pandas`, `boto3`, `matplotlib`, `seaborn` など）を含む環境を準備する。

2.  **モデルとデータの読み込み**
    -   S3に保存されている学習済みモデルファイルをダウンロードし、Pythonスクリプトにロードする。
    -   dbtで作成されたテストデータセットをAthenaなどから読み込む。

3.  **予測の実行と評価指標の計算**
    -   ロードしたモデルを使い、テストデータセットの特徴量から活動ラベルを予測する。
    -   `scikit-learn.metrics` モジュールなどを活用し、以下の評価指標を計算する。
        -   正解率 (Accuracy)
        -   適合率 (Precision)
        -   再現率 (Recall)
        -   F1スコア (F1-Score) - macro平均とweighted平均の両方を計算
        -   混同行列 (Confusion Matrix)

4.  **結果のレポーティング**
    -   計算した評価指標を、標準出力やログファイル、あるいはMarkdownファイルなど、人間が読みやすい形式で出力する。
    -   混同行列を `matplotlib` や `seaborn` を使ってヒートマップとして可視化し、画像ファイルとして保存する。どの活動が誤分類されやすいかを分析する。
    -   （任意）評価結果をJSON形式でS3に保存し、機械的に処理できるようにする。

## 期待される成果物

-   モデルの評価を行うPythonスクリプト（例: `scripts/evaluate_model.py`）。
-   スクリプトを実行すると、テストデータに対するモデルの評価指標が出力されること。
-   混同行列の可視化画像ファイルが生成されること。
-   最終的な評価結果が、論文で報告されている性能と比較できる形でまとめられていること。
