# MHEALTH Model Evaluation Plan: モデル評価

## 1. 目的

学習済みモデルの性能を、未知のテストデータを用いて客観的に評価する。Accuracy や F1スコアなどの標準的な評価指標を計算し、モデルがどの活動を正しく分類でき、どの活動を誤分類しやすいかを分析するための混同行列を作成する。

## 2. 背景

モデルを学習させるだけでは、そのモデルが実世界のデータに対してどれだけうまく機能するかは分からない。評価フェーズは、モデルの汎化性能を定量的に測定し、ビジネスや研究の要求仕様を満たしているかを確認するために不可欠なプロセスである。また、評価結果を分析することで、モデルの改善点や次のアクション（例: 特定の活動データの追加収集、特徴量の見直し）を特定する手がかりが得られる。

## 3. タスク詳細

### 3.1. 学習済みモデルとテストデータの読み込み

- **作業内容**:
    1.  `train_model.py` で保存した学習済みモデルファイル (`.joblib`) を読み込む関数を実装する。
    2.  `train_model.py` と同じデータ分割戦略を用いて、テストデータ (`X_test`, `y_test`) を準備する。この際、データ分割ロジックは共通化して再利用することが望ましい。

### 3.2. 予測の実行と評価指標の計算

- **作業内容**:
    1.  読み込んだモデルを使い、テストデータ `X_test` に対する予測ラベル (`y_pred`) を生成する (`.predict()`)。
    2.  `scikit-learn.metrics` モジュールを利用して、以下の評価指標を計算する関数を実装する。
        - **Accuracy**: 全体的な正解率。
        - **F1-Score (macro/weighted)**: クラスごとの適合率と再現率の調和平均。不均衡データに強い指標。
        - **Classification Report**: 各クラスの適合率 (Precision)、再現率 (Recall)、F1スコアを一覧表示する。
        - **Confusion Matrix**: 混同行列。どのクラスがどのクラスに誤分類されたかを行列で示す。

### 3.3. 評価結果の出力と可視化

- **作業内容**:
    1.  計算した評価指標を、コンソールやテキストファイルに分かりやすく出力する。
    2.  混同行列を `matplotlib` や `seaborn` を使ってヒートマップとして可視化し、画像ファイルとして保存する。これにより、誤分類の傾向を視覚的に把握しやすくなる。
    3.  評価結果を保存するためのディレクトリ `reports/mhealth/` を作成し、評価レポート（テキストファイル）と混同行列の画像ファイルを格納する。

- **成果物**:
    - Pythonスクリリプト: `scripts/mhealth/evaluate_model.py`
    - 評価レポート: `reports/mhealth/evaluation_report_xgboost_YYYYMMDD.txt`
    - 混同行列の画像: `reports/mhealth/confusion_matrix_xgboost_YYYYMMDD.png`

## 4. 完了条件

- `python scripts/mhealth/evaluate_model.py` を実行すると、エラーなく処理が完了する。
- `reports/mhealth/` ディレクトリに、評価指標が記載されたテキストファイルと、混同行列の画像ファイルが正しく出力されている。
- 出力された評価指標が、モデルの性能を客観的に示している。
- スクリプトは、どのモデルファイルとどのデータを使って評価を行ったかが明確にわかるように実装されている。
