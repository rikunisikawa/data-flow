# 7. モデル評価計画

## 目的
学習済みモデルの性能を客観的に評価し、どのモデルがタスクに対して最も優れているかを判断する。

## 手法
- Python (Notebook): Scikit-learnの評価指標計算機能や、プロットライブラリを使用する。

## 評価項目
1.  **評価指標の算出**:
    - テストデータを用いて、以下の指標を計算する。
        - `Accuracy`（正解率）
        - `Precision`（適合率）
        - `Recall`（再現率）
        - `F1-Score`
2.  **混同行列（Confusion Matrix）の作成**:
    - モデルがどのクラスを誤分類しやすいかを可視化する。
3.  **クラスごとの性能評価**:
    - 各活動ラベルごとのPrecision, Recall, F1-Scoreを算出し、モデルの弱点を分析する。
4.  **結果の比較と考察**:
    - 各モデルの評価結果を比較し、過去の研究結果との差異を考察する。
    - 最も性能の良いモデルを選定し、その理由を分析する。
