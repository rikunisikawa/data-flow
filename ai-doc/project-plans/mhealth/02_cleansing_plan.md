# 2. データクレンジング計画

## 目的
データセットに含まれる欠損値、ノイズ、外れ値などを適切に処理し、分析やモデル学習に適したクリーンなデータセットを作成する。

## 手法
- dbt: SQLクエリを用いて、大規模なデータセットに対する基本的なクレンジング処理をモデルとして実装する。
- Python (Notebook): dbtで処理しきれない高度なクレンジング処理や、処理結果の確認を行う。

## 処理項目
1.  **欠損値の特定と処理**:
    - 各列の欠損値の数と割合を確認する。
    - 欠損値の処理方針を決定する。（例: 線形補間、前の値で補完、行ごと削除）
    - dbtモデルで補完処理を実装する。
2.  **ノイズ除去**:
    - センサーデータに含まれる高周波ノイズを特定する。
    - 移動平均フィルタやバターワースフィルタなどの平滑化手法を検討・適用する。
3.  **外れ値の検出と対応**:
    - 箱ひげ図やZスコアを用いて外れ値を検出する。
    - 外れ値の処理方針を決定する。（例: 除去、丸め込み）
4.  **データ型とフォーマットの統一**:
    - すべての列が適切なデータ型（数値、カテゴリなど）になっていることを確認し、必要に応じて修正する。
