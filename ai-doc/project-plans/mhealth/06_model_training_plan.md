# 6. モデル学習計画

## 目的
最終特徴量テーブルを用いて、人間活動認識のための分類モデルを学習させる。過去の研究で良好な性能を示したモデルを再現する。

## 手法
- Python (Notebook): Scikit-learnやXGBoost, LightGBMなどの機械学習ライブラリを使用する。

## タスク
1.  **データ分割**:
    - データセットを学習用（Training）、検証用（Validation）、テスト用（Test）に分割する。
    - 被験者ごとに分割するなど、データのリークを防ぐ方法を検討する。
2.  **特徴量のスケーリング**:
    - `StandardScaler`などを用いて、特徴量のスケールを標準化する。
3.  **モデルの選定**:
    - 過去の研究を参考に、ベースラインとして以下のモデルを学習させる。
        - 多層パーセプトロン（MLP）
        - XGBoost
        - サポートベクターマシン（SVM）
4.  **ハイパーパラメータチューニング**:
    - グリッドサーチやランダムサーチを用いて、検証用データで各モデルのハイパーパラメータを最適化する。
5.  **モデルの学習**:
    - 最適化されたハイパーパラメータを用いて、学習用データ全体でモデルを再学習させる。
