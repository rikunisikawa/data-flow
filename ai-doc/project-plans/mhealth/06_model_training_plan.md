# MHEALTH Model Training Plan: 教師データの分割とモデル学習

## 1. 目的

Python を使用して、dbtで作成した最終特徴量テーブルを学習データとテストデータに分割し、ベースラインとなる機械学習モデル（XGBoost, MLP）を学習させる。再現性を確保し、後の評価フェーズで利用できるように、学習済みモデルをファイルとして保存する。

## 2. 背景

モデルの性能を客観的に評価するためには、学習に使用したデータとは完全に独立したテストデータが必要である。特に、時系列データや被験者データでは、ランダムな分割ではなく、被験者ごとや時間ごとといった特定の戦略に基づいてデータを分割することが重要となる。モデル学習フェーズでは、このデータ分割からモデルのトレーニング、成果物の保存までの一連のパイプラインを構築する。

## 3. タスク詳細

### 3.1. データ分割戦略の決定と実装

- **作業内容**:
    1.  **データ分割戦略を決定する。**
        - **推奨戦略**: **Leave-One-Subject-Out (LOSO)**。被験者のうち1人をテストデータとし、残りの被験者を学習データとする交差検証。これにより、未知の個人に対するモデルの汎化性能を評価できる。今回はまず特定の1名（例: `subject_id` = 1）をテスト、残りを学習とする。
        - **代替戦略**: 単純な時系列分割。あるタイムスタンプを境に過去を学習データ、未来をテストデータとする。
    2.  dbtで作成した `fct_mhealth_final_features` テーブルをS3から読み込み、選択した戦略に基づいてデータを学習用 (`X_train`, `y_train`) とテスト用 (`X_test`, `y_test`) に分割するPython関数を実装する。

### 3.2. モデル学習パイプラインの構築

- **作業内容**:
    1.  `scikit-learn` の `Pipeline` を使用して、前処理（特徴量のスケーリングなど）とモデル学習のステップを連結する。
        - **StandardScaler**: 各特徴量を標準化（平均0, 分散1）する。
        - **モデル**:
            - `XGBClassifier` (XGBoost)
            - `MLPClassifier` (多層パーセプトロン)
    2.  ハイパーパラメータは、まず一般的なデフォルト値や先行研究で用いられている値を使用する。
    3.  構築したパイプラインに学習データ (`X_train`, `y_train`) を投入し、モデルを学習させる (`.fit()`)。

### 3.3. 学習済みモデルの保存

- **作業内容**:
    1.  学習が完了したモデルオブジェクト（`Pipeline` オブジェクト）を、`joblib` や `pickle` を用いてシリアライズし、ファイルとして保存する。
    2.  保存先ディレクトリ `models/mhealth/` を作成し、モデルファイル名にはモデルの種類と学習日時がわかるような命名規則（例: `xgboost_20250823.joblib`）を採用する。

- **成果物**:
    - Pythonスクリプト: `scripts/mhealth/train_model.py`
    - 保存されたモデルファイル: `models/mhealth/xgboost_YYYYMMDD.joblib`, `models/mhealth/mlp_YYYYMMDD.joblib`

## 4. 完了条件

- `python scripts/mhealth/train_model.py` を実行すると、エラーなく処理が完了する。
- 指定されたパスに、学習済みモデルのファイルが正しく保存されている。
- スクリプト内で使用したデータ分割戦略やモデルのハイパーパラメータが、ログやコメントで明確に記録されている。
- 保存されたモデルが、後続の評価スクリプトで正常に読み込めることを確認する。
