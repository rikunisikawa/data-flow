# タスク3.2: PythonによるXGBoostモデルの学習と保存

## 目的

dbtで作成した教師データセット（学習用・検証用）を用いて、Python環境でXGBoostモデルを学習させる。
学習済みモデルは再利用可能な形式でシリアライズし、S3などのオブジェクトストレージに保存する。

## 背景

dbtによってデータの前処理と特徴量エンジニアリング、データセットの作成が完了した。
次のステップは、これらのデータを実際に機械学習モデルに投入し、学習を実行することである。
このタスクでは、再現対象であるXGBoostモデルの学習パイプラインをPythonスクリプトとして実装する。

## 作業内容

1.  **学習環境のセットアップ**
    -   `xgboost`, `pandas`, `scikit-learn`, `boto3`, `pyarrow` などの必要なライブラリを含む `requirements.txt` を作成する。
    -   （任意）学習処理をコンテナ化するための `Dockerfile` を作成する。

2.  **データ読み込みスクリプトの実装**
    -   dbtが作成した学習用および検証用データセットを、AthenaなどからPandas DataFrameとして読み込むPython関数を作成する。
    -   AWS SDK (`boto3`) や `awswrangler` ライブラリの利用を検討する。

3.  **モデル学習スクリプトの実装**
    -   `xgboost.XGBClassifier` を用いてモデルを定義する。
    -   論文で言及されているハイパーパラメータ、または一般的なデフォルト値でモデルを設定する。
    -   `fit` メソッドを用いて、学習用データでモデルを学習させる。検証用データを `eval_set` として指定し、学習過程での性能をモニタリングする（Early Stoppingも活用する）。

4.  **モデルの保存**
    -   学習が完了したモデルオブジェクトを、`joblib` または `pickle` を用いてシリアライズする。
    -   `boto3` を使用して、シリアライズしたモデルファイルをS3バケットの指定のパスにアップロードする。
    -   モデルのバージョンがわかるように、ファイル名にタイムスタンプやGitのコミットハッシュを含めるなどの命名規則を設ける。

## 期待される成果物

-   モデルの学習と保存を行うPythonスクript（例: `scripts/train_model.py`）。
-   依存ライブラリを定義した `requirements.txt`。
-   `python scripts/train_model.py` を実行すると、モデルの学習が実行され、学習済みモデルファイルがS3にアップロードされること。
-   学習中のログ（例: AccuracyやLossの推移）が標準出力またはログファイルに出力されること。
