# 要件: Elementaryで件数/NULL件数/分布指標を可視化

## 背景/Context
- 目的: mHealth の主要テーブルに対し、件数や NULL 件数、値の分布を継続的に把握し、品質劣化を早期検知する。
- 現状: Elementary の導入は進んでいるが、指標として何を可視化するかの仕様が未整理。

## 対象範囲
- 対象モデル: `cleaned_activities` を優先（必要に応じて `featured_activities` を追加）。
- 対象列: 数値列（センサー軸）とラベル列を中心に設定。

## 機能要件（FR）
- FR-1: 行数（row count）を指標として収集・可視化できる。
- FR-2: NULL 件数（null count）を指標として収集・可視化できる。
- FR-3: 値の分布（min/max/avg/p95 など）を指標として収集・可視化できる。
- FR-4: 指標は `edr monitor` のレポートで確認できる。
- FR-5: 既存の dbt 実行フローを崩さずに追加できる。

## 非機能要件（NFR）
- NFR-1: Athena のスキャン量を抑えるため、対象モデル/期間を限定する。
- NFR-2: 構成は再現可能（設定ファイル + dbt/elementary の設定で管理）。
- NFR-3: 秘密情報は既存の環境変数/プロファイルで注入する。

## 設計方針
- Elementary のモデル/テスト/メタデータに依存し、dbt の標準設定で実現する。
- 指標は Elementary のレポートで確認し、外部通知は別途検討。

## 受け入れ基準（Acceptance Criteria）
- AC-1: `edr monitor` の HTML レポートに行数/NULL件数/分布の指標が表示される。
- AC-2: 主要モデルで指標が安定して取得できる（エラーなし）。
- AC-3: 既存の dbt モデル/テストの実行に影響がない。
