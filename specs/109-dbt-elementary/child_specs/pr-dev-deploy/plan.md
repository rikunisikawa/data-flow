# 計画: PR 作成時の dev 自動デプロイ

## 目的
- PR 作成/更新時に dev 環境へ自動反映し、ECR push 忘れや手作業を削減する。

## 前提
- `.github/workflows/` は直接編集禁止（設計・タスク化まで）。
- 本番フロー（main merge）は既存運用を維持。

## 作業ステップ
1) 既存 prod ワークフローの差分整理（role/vars/タグ）。
2) dev 用フローの条件/順序/安全策の設計。
3) 実装タスクの切り出し（別チケット化）。

## 受け入れ条件
- PR 時に dev へ自動デプロイできる設計が確定。
- 実装タスクが明確化されている。
