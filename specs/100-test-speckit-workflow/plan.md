# 計画書

## 1. 目的

この計画は、Issue #100 に基づき、`.github/workflows/auto-pr.yml` のワークフローの仕様を明確にし、開発者がそのフローを理解し活用するためのドキュメントを作成することを目的とします。

## 2. 高レベル計画

本計画は、以下の順序で進めます。依存関係を考慮し、ステップを追って実行します。

1.  **ワークフローの分析:**
    - `.github/workflows/auto-pr.yml` ファイルを精読し、「Planフェーズ」と「Implementフェーズ」のトリガー、処理内容、成果物を完全に理解します。
2.  **仕様書の作成:**
    - 分析結果に基づき、ワークフローの全体像、各フェーズの詳細、そして開発者が従うべき手順を `spec.md` ファイルにまとめます。
3.  **ドキュメント体系の決定:**
    - 作成するドキュメントを、既存のドキュメント構造 (`ai-doc/` ディレクトリ) のどこに配置するのが最も適切かを判断します。今回は、運用に関するドキュメントであるため `ai-doc/operations/` が適切と判断します。
4.  **開発者向けガイドの作成:**
    - 仕様書の内容を基に、開発者がIssueの起票からコードのマージまで、ワークフローを実際に利用する際の具体的な手順を記したガイド (`workflow-usage.md`) を作成します。
5.  **レビュー:**
    - 作成したすべてのドキュメントをレビューし、内容の正確性、明確さ、網羅性を確認します。
