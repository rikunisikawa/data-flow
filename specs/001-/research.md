# 機能調査: データ基盤におけるテストの実装

## 1. Pythonバージョン
- **決定**: Python 3.11 を使用する。
- **根拠**: これは広く使用されている安定したバージョンのPythonであり、AWS Lambdaでサポートされています。既存のプロジェクトファイル（`.python-version`や`runtime.txt`）ではバージョンが指定されていないため、妥当なデフォルトが選択されました。
- **検討された代替案**: Python 3.8, 3.10, 3.11。これらのいずれも許容範囲内である可能性が高いですが、3.9が安全な選択です。

## 2. コードカバレッジ目標
- **決定**: 現時点では特定のコードカバレッジ率を強制しない。
- **根拠**: 当面の目標は、テストフレームワークと初期テストを確立することです。テストを記述する前に厳格なカバレッジ目標を設定するのは時期尚早です。重要な機能に対して意味のあるテストを作成することに焦点を当てるべきです。ベースラインが確立された後、目標を導入することができます。
- **検討された代替案**: 80%の目標を設定する。これは、初期の障壁を作らないようにし、量より質を優先するために却下されました。
