# クイックスタート: データ基盤テスト

このドキュメントは、データ基盤のテストスイートを実行するための手順を説明します。

## 前提条件

- Python 3.11 がインストールされていること。
- `pip` を使って必要な依存関係がインストールされていること。

```bash
pip install -r tests/requirements.txt
```

## テストの実行

プロジェクトのルートディレクトリから以下のコマンドを実行して、テストスイートを実行します。

```bash
pytest
```

## dbtのテスト

dbtのテストを実行するには、`data_flow_dbt`ディレクトリに移動し、以下のコマンドを実行します。

```bash
dbt test
```
