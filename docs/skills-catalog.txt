SKILL: data-intake
パス: .claude/skills/data-intake/SKILL.md
フェーズ: P0（初期リリース）
--------------------------------------------------------------
目的:
  データソースのメタデータを整理し、抽出設計を行う。
  実データの取得・書き込みは行わない。

主要成果物:
  - データ所在マップ（パス/形式/推定サイズ）
  - 小サンプル設計書（実取得なし）
  - 依存関係図（Lambda→S3→Glue→Athena）
  - リスク一覧（欠損/形式不一致/スキーマ変動）

禁止事項:
  - 実データ取得（aws s3 cp, kaggle download 等の実行）
  - S3への書き込み
  - Lambda/Glue Jobの起動

トリガー条件:
  - "データがどこにあるか確認したい"
  - "新しいデータソースを追加したい"
  - "データ所在マップを作りたい"


--------------------------------------------------------------
SKILL: schema-contract
パス: .claude/skills/schema-contract/SKILL.md
フェーズ: P0（初期リリース）
--------------------------------------------------------------
目的:
  データスキーマの契約定義を行う。
  NULL許容・型・値範囲を明示し、将来のテスト自動化に備える。
  DDL/DMLの実行は行わない。

主要成果物:
  - スキーマ契約書（カラム/型/NULL/値域）
  - 整合性チェックリスト（将来のテストケース候補）
  - 型不一致リスク表（ログ→Parquet変換時の注意点）
  - Athena互換型マッピング

禁止事項:
  - DDL実行（CREATE TABLE, ALTER TABLE 等）
  - DML実行（INSERT, UPDATE, DELETE 等）
  - Athena/Glueへの直接クエリ

トリガー条件:
  - "スキーマを定義したい"
  - "カラムのNULLポリシーを決めたい"
  - "型の契約書を作りたい"


--------------------------------------------------------------
SKILL: sql-generator
パス: .claude/skills/sql-generator/SKILL.md
フェーズ: P0（初期リリース）
--------------------------------------------------------------
目的:
  Athena向けのSQLを説明責任・コスト配慮コメント付きで生成する。
  SQLの実行は行わない。

主要成果物:
  - 分析SQL（集計/フィルタ/時系列等）
  - コスト見積もりコメント（スキャンサイズの目安）
  - 最適化ヒント（パーティション活用等）
  - 実行前チェックリスト

禁止事項:
  - SQLの実行（Athena API呼び出し等）
  - DDL/DML文の生成（SELECT以外）
  - 結果データの取得・保存

トリガー条件:
  - "AthenaでSQLを書きたい"
  - "集計クエリを作りたい"
  - "コスト効率の良いSQLが欲しい"

SKILL: eda-notebook
パス: .claude/skills/eda-notebook/SKILL.md
フェーズ: P0（初期リリース）
--------------------------------------------------------------
目的:
  小サンプルデータを前提としたEDAノートブックテンプレートを生成し、
  分析仮説リストを出力する。大規模データの直接読み込みは行わない。

主要成果物:
  - EDAノートブックテンプレート（Jupyter形式の骨格）
  - 分析仮説リスト（検証すべき仮説の列挙）
  - 可視化プラン（グラフ種別/軸/フィルタ条件）
  - 小サンプル戦略（本番データを使わない検証設計）

禁止事項:
  - 大規模データの直接読み込み（フルスキャン等）
  - S3への書き込み
  - Jupyter Kernelの実行

トリガー条件:
  - "EDAを始めたい"
  - "データの分析テンプレートが欲しい"
  - "分析仮説を整理したい"


--------------------------------------------------------------
SKILL: data-governance-guard
パス: .claude/skills/data-governance-guard/SKILL.md
フェーズ: P0（初期リリース）
--------------------------------------------------------------
目的:
  データ内のPII疑いカラムを分類し、
  承認必要性の提示とマスキング方針を策定する。
  データへのアクセス・変更は行わない。

主要成果物:
  - PIIリスク分類表（カラム別リスクレベル）
  - 承認マトリックス（利用用途別に必要な承認レベル）
  - マスキング方針（PIIカラムの処理方針）
  - コンプライアンスチェックリスト

禁止事項:
  - 実データへのアクセス
  - マスキング処理の実行
  - データの削除・変更
  - PIIデータを含むログの出力

トリガー条件:
  - "PIIリスクを評価したい"
  - "データの承認レベルを確認したい"
  - "マスキング方針を決めたい"
  - "コンプライアンスチェックをしたい"
