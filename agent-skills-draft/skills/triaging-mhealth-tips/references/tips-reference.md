# Tips Reference

## Mermaid
- Avoid parentheses and symbols in subgraph names and node labels.
- Replace newline characters with `<br/>`.
- Keep labels alphanumeric where possible.

## Notebooks (.ipynb)
- Ensure the file is a single JSON object.
- Include `nbformat`, `nbformat_minor`, `metadata.kernelspec`, `metadata.language_info`, and `cells`.
- Regenerate a minimal notebook when corruption is suspected.
